# Ktpt.CourseOrder — «Библиотека»

Курсовой проект: настольное приложение для учёта книжного фонда библиотеки колледжа. В нём ведётся каталог книг, учитываются экземпляры, выдачи и возвраты, а также читатели.

## Возможности

- **Каталог книг.** Карточки с обложкой, автором, издательством, годом, ISBN и жанром. Для каждой книги есть подробная страница со списком экземпляров и их статусами.
- **Добавление книг и экземпляров.** Новые книги и экземпляры добавляются с указанием полки, можно сразу несколько штук.
- **Выдача и возврат книг.**
  - Срок выдачи — 14 дней.
  - На руках у читателя может быть не больше 5 книг.
  - Читателю с просроченной книгой новая не выдаётся.
  - Один экземпляр нельзя выдать дважды: выдача идёт в транзакции с уровнем изоляции `Serializable`.
- **Читатели.** Список, карточка читателя с историей выдач, добавление нового читателя и редактирование данных.
- **Вход и роли.**
  - **Гость** — просмотр каталога.
  - **Читатель** — видит только свой профиль и свои выдачи.
  - **Библиотекарь** — выдача и возврат книг, просмотр всех читателей и выдач.
  - **Администратор** — всё то же самое, плюс добавление книг и читателей и редактирование данных читателей. Если у пользователя задан пароль, при входе его нужно ввести.

## Технологии

| | |
|---|---|
| Язык / платформа | C#, .NET 10 |
| Интерфейс | [Avalonia UI](https://avaloniaui.net/) 12 (тема Fluent) |
| Доступ к данным | Entity Framework Core 10 (модели получены через scaffold из БД) |
| СУБД | Microsoft SQL Server |

## Структура проекта

```
Ktpt.CourseOrder/
├── Assets/          # иконка, логотип, обложки книг
├── Data/
│   ├── CollegeContext.cs   # контекст EF Core
│   └── Db.cs               # создание контекста по строке из connection.txt
├── Models/          # сущности БД + ModelExtras.cs (вычисляемые свойства для UI)
├── Services/        # бизнес-логика: каталог, выдачи, пользователи, сессия, правила
├── Views/           # окна и страницы Avalonia (.axaml + code-behind)
├── App.axaml        # стили приложения
├── Program.cs       # точка входа
└── connection.txt   # строка подключения к SQL Server
```

Таблицы базы данных: `Books`, `Authors`, `BookAuthors`, `Publishers`, `Copies`, `Loans`, `LoanStatuses`, `Users`, `Roles`.

## Скачать готовую программу

На странице [Releases](../../releases/latest) скачайте архив `Ktpt.CourseOrder-…-win-x64.zip` и распакуйте его. Затем впишите свой SQL Server в `connection.txt` и запустите `Ktpt.CourseOrder.exe`. Устанавливать .NET не нужно.

Новый релиз собирается автоматически при пуше тега вида `v*`, например `git tag v1.1.0 && git push --tags`.

## Сборка из исходников

1. Установите [.NET 10 SDK](https://dotnet.microsoft.com/download) и SQL Server.
2. Разверните базу данных `library` на своём сервере.
3. Укажите свой сервер в `connection.txt`, например:
   ```
   Server=.\SQLEXPRESS;Database=library;Trusted_Connection=True;Encrypt=True;TrustServerCertificate=True;Connect Timeout=5
   ```
   Файл копируется рядом с `.exe`, поэтому строку подключения можно менять без пересборки.
4. Соберите и запустите приложение:
   ```bash
   dotnet run
   ```
   Можно также открыть `Ktpt.CourseOrder.slnx` в Visual Studio и нажать F5.

### Обновление моделей из БД

В проекте подключён локальный инструмент `dotnet-ef`:

```bash
dotnet tool restore
dotnet ef dbcontext scaffold "<строка подключения>" Microsoft.EntityFrameworkCore.SqlServer -o Models --context-dir Data -c CollegeContext --force
```

После scaffold файл `Models/ModelExtras.cs` сохраняется, потому что дополнительные свойства вынесены в `partial`-классы.
